# STRONG TYCOON

3D-тайкун пляжного зала: турники, гири, ринг — и очередь качков с абонементами.

**[⬇ Скачать APK](https://github.com/zakriden-commits/yberi/releases/latest)** · Android 7+ · офлайн

## Как играть

- Клиенты приходят на пляж, покупают абонемент и занимаются на снаряде.
- Чек за абонемент капает сразу: чем дороже абонемент и чем больше клиентов
  одновременно — тем выше доход (за crowd-бонус отвечает ажиотаж).
- **Улучшения:** реклама (больше людей), снаряды (больше мест), оборудование
  (дороже чек), тренер (чек + скорость тренировки), темп (ускоряет время в зале).
- **Каталог абонементов:** «Пробный» 1 мин → «Стандарт» 3 мин → «Про» 5 мин
  (максимум по правилам зала). Дорогие абонементы нужно сначала открыть.
- Прогресс сохраняется автоматически, офлайн-доход начисляется за время отсутствия.

## Технически

| Что | Где |
|---|---|
| Сцена, персонажи, звук, интерфейс | `www/app.js` (один большой файл) |
| Экономика (чистая логика, без DOM) | `www/economy.js` |
| Разметка и стили | `www/index.html`, `www/styles.css` |
| 3D-движок | `www/vendor/three.module.js` (three r187, локально) |
| Нативная обёртка | `android/` (Capacitor 8) |
| Сборка | `.github/workflows/android.yml` |

Логотип: `www/assets/logo.png`. Иконки приложения генерируются из него
скриптом `scripts/make-icons.cjs`.

## Разработка

```bash
npm install
npm run serve        # http://localhost:5173
npm test             # 20 проверок экономики
```

Собрать APK локально (нужны Android SDK + JDK 21):

```bash
npx cap sync android
cd android && ./gradlew assembleRelease
```

Или запушьте тег `v*` — GitHub Actions соберёт и опубликует APK и AAB.

## Подпись

`android/keystore.properties` ссылается на публичный тестовый ключ
(`android/keystore/strongtycoon.p12`, пароль `strongtycoon`). Он нужен, чтобы
обновления из CI ставились поверх старой версии.

Перед публикацией в магазин на реальную аудиторию сгенерируйте свой ключ
и держите его в секрете:

```bash
keytool -genkeypair -v -keystore my-release.jks -alias upload \
  -keyalg RSA -keysize 2048 -validity 10000
```
