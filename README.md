# TurnikMan

Пародийный 3D-симулятор турника: качаешься на перекладине, отпускаешься, крутишь сальто,
ловишь турник обратно и уходишь на чистое приземление. Монеты за трюки идут в магазин скинов.

## Запуск

```bash
npm install      # three.js кладётся в node_modules, копия уже лежит в www/vendor
npm run serve    # http://localhost:5173  (слушает 0.0.0.0 — зайдёт и с телефона по Wi-Fi)
npm test         # 33 юнит-проверки + 29 проверок headless-прогона
```

Открывать нужно через сервер: это ES-модули, с `file://` браузер их не загрузит.

## Управление

| Кнопка | Клавиша | Что делает |
|---|---|---|
| МАХ | A / ← | раскачка маятника |
| ДЕЙСТВИЕ | Space | отпустить турник в висе · схватиться в полёте |
| ГРУППА | D / → / Shift | группировка: радиус меньше, вращение быстрее |

## Что внутри

- `www/physics.js` — маятник с переменным радиусом и моментом инерции, отрыв, полёт,
  сохранение момента при смене позы, подсчёт сальто, захват, приземление, очки.
  Чистая логика без DOM и three.js — поэтому её можно тестировать в Node.
- `www/content.js` — 8 скинов, 4 карты, магазин, сохранение в localStorage (`turnikman.save.v1`).
- `www/app.js` — сцена three.js, 4 карты, процедурный персонаж с позами, WebAudio, игровой цикл
  (фиксированный шаг физики 1/120 с), привязка интерфейса.
- `test/*.test.mjs` — юнит-проверки физики и контента.
- `test/headless.mjs` — прогон настоящего `app.js` с заглушками three.js и DOM: ловит ошибки
  выполнения, которых не видит `node --check`.

## Карты

Двор · Пляж · Зал · Парк (в парке две перекладины — можно перелетать с одной на другую).
