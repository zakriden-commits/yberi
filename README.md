# Сасный Нурмадог

Небольшая мобильная игра-звуковая панель на русском языке. Выбери один из четырёх кадров (или своё фото), нажимай на него и слушай семь разных синтезированных звуковых эффектов. Эффекты собираются в браузере через Web Audio API — отдельные аудиофайлы и интернет для игры не нужны.

## Android

Windows-файл `.exe` на Android не запускается. Поэтому игра сделана как **устанавливаемое веб-приложение (PWA)**: открой опубликованную страницу в Chrome на Android, нажми **⋮ → Установить приложение** или **Добавить на главный экран**. После первого открытия игра сохраняется и работает офлайн. Если появилась кнопка «Установить», можно нажать прямо на неё.

Свои фотографии обрабатываются только в открытой вкладке браузера и никуда не отправляются.

## Публикация через GitHub Pages

В репозитории открой **Settings → Pages** и выбери **GitHub Actions** в качестве источника публикации. Workflow `.github/workflows/deploy-pages.yml` развернёт статическую игру при push в `main` или в ветку Arena этой задачи. После успешного workflow ссылка появится в разделе **Settings → Pages** и в окружении `github-pages` у запуска Actions.

## Запуск локально

Из корня репозитория запусти любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`. Для установки PWA и офлайн-режима нужна защищённая страница (HTTPS); локальный `localhost` также подходит для разработки.
