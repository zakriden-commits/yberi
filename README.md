# Deni Islam

Кооперативная 3D-онлайн-игра на **2 игроков** для браузера, iPhone (PWA) и Android (APK через GitHub Actions).

## Запуск локально

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`. Сервер слушает `0.0.0.0`, поэтому телефон в той же сети может открыть `http://<IP-компьютера>:3000`.

## Онлайн

Один сервер = одна комната на 2 человека. Первый игрок — джентльмен, второй — гопник. Прогресс (баланс, инвентарь, общий шкаф) сохраняется в `data/save.json` на сервере.

Для iPhone открой ссылку в Safari и добавь «На экран Домой». Для Android скачай APK из GitHub Actions (workflow **Android APK**, артефакт `DeniIslam-debug-apk`). В меню можно указать адрес сервера, если играешь не с того же хоста.

## Управление

- ПК: WASD, мышь, Shift — бег, E — действие, R — перезарядка, ЛКМ — огонь, 1–6 — слоты.
- Телефон: джойстик слева, обзор справа, кнопки ОГОНЬ / E / R / БЕГ.

## Геймплей

- Спавн на кроватях в общем доме.
- Улица с NPC: обычные, пожилые, «плохие»; они смотрят на игроков.
- Подработка: бригадир подходит и предлагает донести ящик до грузовика.
- Оружейный магазин: пистолет, ПП, винтовка, патроны, сумка.
- Банк: касса, охрана, деньги. Без сумки — 15 сек на 5 пачек, с сумкой — 30 сек.
- Тревога: если показать оружие в банке или попасться охране на краже.
- Полиция: звёзды розыска, погоня, урон. Дружественный огонь отключён.
- Прячься дома с закрытой дверью — звёзды постепенно уходят.
- Смерть: инвентарь пропадает, респаун дома.
- Шкаф: общий тайник на 15 предметов, сохраняется.
- Голосовой чат: WebRTC, микрофон запрашивается при каждом входе.

## Сборка

```bash
npm run build
npm start
```

APK собирается в GitHub Actions: `.github/workflows/android.yml`.
