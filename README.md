# ПОРОГ — тестовая 3D-сцена

Атмосферный прототип от первого лица для **ПК и телефона**. Один полуразрушенный деревянный дом и пустая улица. Это одиночная тестовая сцена: мультиплеера, заданий и APK пока нет.

## Что уже есть

- кинематографичное падение с потолка на спавне;
- тряска камеры, приседание при приземлении, пыль и синтезированные звуки;
- деревянный дом с проломами, досками, старой мебелью и открытой дверью;
- пустая улица за домом;
- ходьба и столкновения со стенами/мебелью;
- сенсорный джойстик и обзор пальцем;
- пауза, повтор падения, звук, громкость и отключение тряски;
- автоматическое снижение качества на слабых устройствах.

Все модели и текстуры генерируются кодом. Звуки синтезируются через Web Audio API — внешние ассеты не загружаются.

## Запуск

Нужен Node.js 22+.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`). Сервер слушает `0.0.0.0`, поэтому телефон в той же сети может открыть `http://<IP-компьютера>:5173`.

Production-сборка:

```bash
npm run build
npm run preview
```

## Управление

| Действие | ПК | Телефон |
|---|---|---|
| Ходьба | `W A S D` или стрелки | джойстик слева |
| Обзор | мышь | свайп справа |
| Быстрее | `Shift` | — |
| Пауза | `Esc` / `P` | кнопка паузы |
| Повтор падения | `R` | меню паузы |
| Звук | `M` | кнопка звука |
| Пропустить падение | `Пробел` | кнопка пропуска |

Если браузер не даёт захватить мышь, зажми левую кнопку мыши на сцене и веди мышью.

## Проверки

```bash
npm test          # физика и столкновения
npm run build     # TypeScript + production-сборка
```

Браузерные тесты:

```bash
npx playwright install chromium
npm run test:e2e
```

Они проверяют падение, выход на улицу, паузу, звук, повтор, мобильный джойстик и обзор.

## Стек

- Babylon.js — 3D-рендер;
- TypeScript + Vite — приложение и сборка;
- Web Audio API — звук;
- Playwright — браузерные проверки.

src/game/audio.ts      синтез звука
